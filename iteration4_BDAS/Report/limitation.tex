The experiments use a single 319-record cohort. Five holdout splits overlap and cannot be treated as independent clinical replications. Training-only cross-validation protects test separation, but selecting the best trial creates optimism in the reported CV score. Twenty trials explore the documented ranges without proving a global optimum. Threshold 0.5 is fixed; screening suitability requires external assessment of sensitivity, calibration and clinical consequences.

Ordinal categories retain their supplied numeric codes. This preserves the dataset representation but imposes ordering for linear models; it remains a modelling assumption. The principal five-family implementation uses scikit-learn, XGBoost and LightGBM. The optional native Spark workflow uses Spark's own logistic regression, random forest and gradient-boosted trees and is a distinct supplementary implementation; its results are not attributed to these Python-library models.
