\subsection{Evidence Provenance}
The native baseline table is extracted from the author's saved Colab display in \path{PySpark/run_spark_workflow.ipynb}. The retained source commit and display precision are recorded in \path{results/spark_colab_reference/provenance.json}. The table contains fifteen measured model/seed evaluations, not fifteen independent cohorts. Its displayed values were rounded to six decimal places. New Spark extension outputs record runtime versions, code/data signatures, saved split membership, selected fields and CV search evidence. Scores are included in the report only when the corresponding native execution is complete.
