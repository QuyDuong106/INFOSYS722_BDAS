\subsection{Retained Python Prototype Execution}
Five seeds (42, 7, 21, 84, 123) each produce a 223-record training partition and a 96-record test partition. Four preparation variants are benchmarked with fixed settings for five predictive families and the training-prior dummy. The predeclared RFE/standardization variant additionally receives training-only Optuna searches for all five predictive families. The dummy has no tunable hyperparameters. No test record enters an inner CV fit or parameter search.
